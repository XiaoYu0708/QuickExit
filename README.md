# QuickExit — 副本退出快捷鍵

按一個自訂快捷鍵，程式會自動「喚出滑鼠 → 移到右上角退出按鈕 → 點擊」，不用再手動按 Ctrl 加滑鼠點。
所有設定都在程式視窗裡完成，改完自動儲存。

## 使用方式

1. 把 `QuickExit.exe` 放在一個**可以寫入**的資料夾（例如桌面或 `D:\Tools\QuickExit`，不要放在 `Program Files`）。
2. 雙擊執行，允許系統管理員權限（遊戲通常以管理員身分執行，沒有權限就送不出點擊）。
   設定會存在同一個資料夾的 `config.toml`。
3. **校正位置（第一次必做）**
   進入遊戲 → 按 `Shift+F3`（會有提示音）→ 叫出滑鼠 → 用**左鍵點一下**右上角「退出」按鈕。
   這次點擊會被程式攔截、不會傳給遊戲，所以不會真的退出副本。按 Esc 或 20 秒內沒點擊就會取消。
   聽到「叮」一聲代表成功，程式會記住位置，並自動把快捷鍵綁定到這個遊戲。
4. 之後在副本內按 `F3` 就會自動點擊退出。

關閉視窗即結束程式（最小化則繼續在背景運作）。

## 視窗裡可以設定的項目

| 區塊 | 項目 |
|---|---|
| 頂端 | 啟用 / 暫停快捷鍵、目前權限、以管理員身分重新啟動 |
| 快捷鍵 | 自動退出（預設 `F3`）、校正按鈕位置（預設 `Shift+F3`）。點按鈕後直接按下想用的鍵即可錄製，可搭配 Ctrl / Alt / Shift，也支援滑鼠中鍵與側鍵；Esc 取消 |
| 喚出滑鼠 | 方式（按住 / 按一下 / 不按）、喚出鍵（LCtrl、RCtrl、LAlt…）、等待滑鼠出現的時間 |
| 點擊 | 退出按鈕位置（畫面比例）、移到按鈕後等待時間、左鍵按住時間、點完把滑鼠移回原位 |
| 目標程式 | 只在這個程式在前景時生效（校正時自動填入）、啟動時自動要求管理員權限 |
| 紀錄 | 每次點擊、校正的結果 |

快捷鍵被觸發時會被攔截，不會傳到遊戲；設定了目標程式後，在其他視窗按同樣的鍵完全不受影響。

### 喚出滑鼠的方式

| 方式 | 行為 | 適用 |
|---|---|---|
| 按住喚出鍵（預設） | 點擊期間一直按住 Ctrl | 遊戲設定「按住 Ctrl」或「按一下 Ctrl」都適用 |
| 按一下喚出鍵 | 先按一下 Ctrl，可選擇點完再按一下收起 | 「按一下 Ctrl」切換模式 |
| 不按鍵 | 不按任何鍵 | 滑鼠本來就看得到時 |

> 注意：如果你用的是「按一下切換」模式，而且觸發前滑鼠**已經是叫出來的狀態**，
> 「按住」會把滑鼠切回隱藏，導致點不到。這種情況請先把滑鼠收起來再按快捷鍵。

## 點不到 / 沒反應時

- **完全沒反應**：確認視窗上方顯示「● 系統管理員」，以及「啟用快捷鍵」有勾選。
- **滑鼠有移過去但沒點到**：把「等待滑鼠出現」或「移到按鈕後等待」調大（例如 300 / 150 ms）。
- **點的位置偏掉**：重新用校正快捷鍵校正。位置以畫面比例儲存，換解析度通常不用重新校正。
- **換遊戲 / 目標程式綁錯**：在「目標程式」按「清除」，再校正一次。

## 注意

本工具是模擬鍵盤與滑鼠輸入。部分線上遊戲的使用條款禁止外部輸入工具，請自行評估風險。

## 開發

- 語言：Rust，GUI 使用 egui / eframe（`x86_64-pc-windows-gnu` 工具鏈，不需要 Visual Studio）
- 編譯 + 打包：`powershell -ExecutionPolicy Bypass -File .\build.ps1` → 輸出 `dist\QuickExit-v<版本>.zip`
- 測試：`cargo test`

### 在精簡 GNU 工具鏈下編譯的注意事項

rustup 內建的 mingw 只有精簡版 `ld`，所以專案做了這些調整：

- `ld` 不支援中文路徑：`build.ps1` 偵測到專案路徑含非英文字元時，會自動把編譯輸出放到 `%LOCALAPPDATA%\quick-exit-target`。
  手動執行 `cargo` 時，請先設定 `$env:CARGO_TARGET_DIR`，或自行建立（不納入版本控制的）`.cargo/config.toml` 指定 `target-dir`。
- `Cargo.lock` 固定 `parking_lot`、`parking_lot_core`、`libloading`、`webbrowser` 的舊版本：
  新版改用 `raw-dylib`，需要完整的 `dlltool` + `as`。**不要對這幾個套件執行 `cargo update`。**
- `link/libshlwapi.a`（空檔）+ `build.rs`：`webbrowser` 會連結 shlwapi，所需函式其實已由 windows-targets 提供。
- `[profile.dev] lto = "fat"`：不開 LTO 時 debug 版連結會無訊息失敗。

### 版本控制流程

1. 修改程式並 commit。
2. 發佈新版時：修改 `Cargo.toml` 的 `version`、在 `CHANGELOG.md` 新增一段。
3. `git commit -am "Release vX.Y.Z"`，`git tag -a vX.Y.Z -m "vX.Y.Z"`。
4. 執行 `build.ps1` 產生 zip。

| 檔案 | 說明 |
|---|---|
| `src/main.rs` | 啟動流程（權限、單一執行個體、開視窗） |
| `src/app.rs` | 設定視窗 |
| `src/engine.rs` | 全域鍵盤/滑鼠 Hook、快捷鍵錄製、自動點擊、校正 |
| `src/config.rs` | 設定檔讀寫（帶註解的 TOML） |
| `src/hotkey.rs` | 快捷鍵字串解析與產生 |
| `src/win.rs` | Win32 輔助：視窗位置、模擬按鍵與點擊、權限 |
